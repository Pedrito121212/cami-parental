Cami Parental 🌸

Aplicación de Protección para el Teléfono de Camilita

📲 Descargar App (Archivo APK)

Versión 1.0.0 • Compatible con Android 8 a 14+ • 100% Gratuito y Privado

📝 Cómo instalar en el teléfono Android:

1
Toca el botón rosa de arriba "Descargar App".
2
Abre el archivo descargado. Si Chrome te pregunta, pulsa "Permitir instalar aplicaciones de esta fuente".
3
Abre la aplicación Cami y pulsa "Escanear Código QR" o escribe el código de papá/mamá para activarla.
